# Prueba con 5 usuarios reales · S5-06

**Objetivo:** ver dónde se traba una persona que nunca ha visto la plataforma. No se le ayuda; solo se observa y se anota.

## Guion para cada persona (10–15 min)

1. Abre https://henaomike11-ux.github.io/lms-nodo-academy/ desde tu celular.
2. Encuentra el curso *Git y GitHub para Equipos* y dime cuánto cuesta.
3. Crea una cuenta (o entra con Google).
4. Compra el curso (modo prueba: tarjeta 4242 4242 4242 4242, fecha futura, CVC 123).
5. Entra al aula y marca la primera lección como completada.
6. Vuelve a *Mis cursos* y dime qué porcentaje llevas.
7. Deja tus datos en el formulario "Quiero más información" del inicio.
